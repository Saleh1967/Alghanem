# SLGE — من البتّ إلى الجواب، وكلُّ سطرٍ بوسم برهانه

الهدف جوابٌ عربيٌّ ينافس جوابَ النماذج اللغويّة الكبيرة، ويختلف عنها في أمرٍ واحد: كلُّ جملةٍ فيه
تحمل وسمَها (مبرهن، مفحوص، دليل، معلن، رأي) وسندَها (مبرهنةٌ في Lean، أو اختبار، أو مصدرٌ ببصمته).
والمنهجُ منهجُ النبهاني في «التفكير»: الحكمُ بالمعلومات السابقة لا بالآراء. فما يقترحه مولِّدٌ
رأيٌ لا يُنتج حتى يقبله شاهدٌ مستقلّ.

```
أيحرم قول أف؟
• نعم: محرم. ⟦دليل · Outcome.منتج⟧
• لأنّ «أف» يلزمه «محرم». ⟦دليل · أف-محرم ← corpora/quran-simple-enhanced.txt⟧
• وصورةُ «عين المقدَّم» منتجةٌ في اخص. ⟦مبرهن · lean:Slge.Ghazali.ghazali_table⟧

أيحرم الضرب؟
• لا أحكم: المعلوماتُ المقبولةُ لا تكفي. ⟦معلن · Outcome.ناقص⟧
• ولو قُبل المقترَحُ لكان: محرم. ⟦رأي · مرشَّحٌ لم يُقبل: ضرب-أذى، أذى-محرم⟧
```

(مثالٌ من `tests/test_answer.py`، على عالمٍ صغيرٍ للاختبار.)

## الطبقات

| الوحدة | الطبقة | ما فيها | أقوى وسم |
|---|---|---|---|
| `cells` | البتّات | الـ116، الترخيص، ‎U(n)‎، الطيّ والفكّ | مبرهن (Lean، لكلّ طول) |
| `phonology` | الصفات | الصفاتُ العشرة والمخارج | معلن |
| `encoding` | اليونيكود | التطبيع، كشفُ التعارض | مفحوص استقصاءً |
| `orthography` | الإملاء | الذرّات ⇄ الرسم، الابتداء، الوصل، الوقف | مفحوص استقصاءً (‎≤ 3‎) |
| `semantics` | الدلالة | الوضع، الدلالات الثلاث، المنطوق والمفهوم | معلن |
| `lexicon` | المبنيّات | الأدوات والمبنيّات من رسمها | مفحوص استقصاءً |
| `morphology` | الصرف | الأوزان، الزوائد، الإعراب، المقامات | مفحوص استقصاءً |
| `knowledge` | المعرفة | قواعدُ بدرجةٍ ومنزلةٍ ودليل؛ `infer` | مبرهن (صورُ الغزالي بالبتّات) |
| `learning` | التعلّم | حلقةٌ مغلقة: اقتراح ← شاهد ← قياس ← سحب | مفحوص |
| `answer` | الجواب | جملٌ موسومة؛ مُعيدُ صياغةٍ لا يُسقط الوسم | مفحوص |

والسجلُّ الكامل لكلّ قانونٍ ووسمه وسنده في [STATUS.md](STATUS.md)، مولَّدًا من `src/slge/status.py`.
والقرارات المعماريّة في [ARCHITECTURE.md](ARCHITECTURE.md).

## التشغيل

```sh
pip install -r requirements-dev.txt && pip install -e . --no-deps
ruff check . && mypy && pytest -q          # البايثون (و`-m "not slow"` للسريع)
python tools/gen_status.py --check         # STATUS.md مولَّدٌ لا محرَّر
cd formal && lake build && lake env lean Audit.lean   # البرهان (Lean 4.34.1، بلا Mathlib)
```

البرهانُ في `formal/` يعتمد على `formal/a116` في مستودع الغانم بإيداعٍ مثبَّت، فلا برهانَ مكرَّر.
